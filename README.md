# Marky's Barber Shop Appointment System

## About the Project

The Marky's Barber Shop Appointment System is a Python console-based application developed to help organize customer appointments at Marky's Barber Shop in El Salvador City, Misamis Oriental.

The system allows customers to register, log in, create appointments, check their scheduled appointments, and cancel appointments. It also provides the Owner/Barber with features to view and manage appointment records.

## Features

### Customer Features
- Customer Registration
- Customer Login
- Create Appointment
- Check My Appointment
- Cancel Appointment

### Admin Features
- Admin Login
- View Appointments
- Approve Appointments
- View Registered Accounts
- Create Appointments
- Cancel/Update Appointments
- View Appointment Records
